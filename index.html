Projetos

Lixie

LIXIE é uma plataforma web completa de incentivo à reciclagem, com sistema de login/cadastro, mapa de pontos de coleta, registro de reciclagens, ranking de usuários e sistema de recompensas. Possui painel administrativo próprio para gestão de usuários e reciclagens registradas.

Ferramentas: Python, MySQL, bcrypt (segurança de senhas), Cloudinary (armazenamento de imagens), HTML, CSS, JavaScript.

Geometry Trash

Geometry Trash é um jogo web inspirado no estilo "Geometry Dash", desenvolvido em grupo com um propósito de conscientização ambiental. O jogador controla uma lata de lixo em movimento contínuo, precisando desviar de obstáculos e pular entre plataformas para avançar em 3 níveis de dificuldade.

Ferramentas: JavaScript, p5.js e p5play (motor de jogo e física), HTML5, CSS3

Chave de Segurança

Projeto de Segurança da Informação com foco em criptografia e certificação digital. Desenvolvi um servidor HTTPS em Java capaz de gerar e configurar seu próprio certificado SSL/TLS, estabelecendo conexões seguras e criptografadas via protocolo HTTPS na porta 8443.

Ferramentas: Java, HttpsServer (com.sun.net.httpserver), SSL/TLS, KeyStore (JKS), Maven
